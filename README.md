# 코인 추천 (Bitget 선물용) — 핸드폰에서 보기

파일 4개가 한 세트입니다: `app.py`, `app_logic.py`, `crypto_market_regime.py`, `requirements.txt`

## 방법 A. Streamlit Community Cloud (가장 쉬움, 무료)

1. GitHub에 새 저장소를 만들고 위 파일 4개를 올립니다.
2. https://share.streamlit.io 에서 **New app** → 저장소 선택 → Main file: `app.py` → **Deploy**
3. 나온 주소(`https://○○○.streamlit.app`)를 폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 씁니다.

주의할 점
- 서버가 해외(주로 미국)에 있어서 **일부 거래소는 접속이 차단될 수 있습니다.**
  프로그램이 막힌 거래소는 건너뛰고 다음 거래소를 쓰지만, 전부 막히면 화면에 오류가 표시됩니다.
- 앱이 재시작·절전되면 **저장 파일이 초기화**됩니다. 그러면 BTC.D·USDT.D·TOTAL 추세 기록과
  매매 결과 기록이 쌓이지 않아서, 국면 판단이 항상 "BTC 가격 추세 기준"으로만 나옵니다.
- 주소를 아는 사람은 누구나 볼 수 있습니다. **API 키는 어디에도 넣지 마세요** (이 프로그램은 키가 필요 없습니다).

## 방법 B. 내 PC 또는 서버에서 실행 (기록이 계속 쌓임, 권장)

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

- 같은 Wi-Fi의 폰에서 `http://PC의 IP주소:8501` 로 접속합니다.
- 밖에서도 보려면 PC/서버에 **Tailscale** 같은 사설 VPN을 깔고 폰에서도 연결하는 방법이 안전합니다.
- 24시간 켜둘수록 BTC.D 등 시장 기록이 쌓여서 국면 판단이 정확해집니다.
  (한국 서버라면 거래소 지역 차단 문제도 거의 없습니다.)

## 화면 사용법

- 처음 열면 자동으로 분석합니다 (1~3분). 이후에는 설정한 주기(기본 15분)마다 접속할 때 자동 갱신됩니다.
- **✅ 진입 검토**: 진입가에 도달한 코인 / **⏳ 대기**: 지정가만 걸고 기다릴 코인
- 카드의 **📋 주문 메모**를 복사해서 Bitget 주문 화면에 붙여 참고하세요.
- 오류가 나면 화면의 오류 내용을 그대로 복사해서 알려주세요.

## 꼭 알아두세요

- 4시간봉 기준 스윙 신호입니다. 초단타용이 아닙니다.
- 자동 주문 기능은 없습니다. 주문은 직접 넣습니다.
- 이 프로그램은 아직 **실제 거래소 데이터로 검증된 적이 없습니다.** 실전 자금을 쓰기 전에
  최소 2~4주는 신호를 지켜보며 모의로 기록하고, `python crypto_market_regime.py --validate` 결과도 확인하세요.
- 손절은 반드시 지키고, 감당 가능한 금액만 사용하세요.
